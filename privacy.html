Privacy Policy

How this demonstration website handles visitor information.

Important Notice

This is a fictional privacy policy for a demonstration website. BrightSmile Dental Studio is not a real dental practice. This policy describes how the demo website functions. If this were a real clinic, a comprehensive privacy policy compliant with applicable laws (including HIPAA for healthcare providers in the United States) would be required.

1. About This Website

BrightSmile Dental Studio is a fictional dental clinic website created as a portfolio demonstration by Vireon Technologies. This website does not offer real dental services, does not operate as a healthcare provider, and does not collect or process patient health information.

2. Information We Do Not Collect

This demonstration website does not:

  • Collect or transmit personal information from the contact form
  • Use cookies, localStorage, sessionStorage, or browser-based data storage
  • Include third-party analytics, tracking scripts, or advertising
  • Process payment or insurance information
  • Collect health information, diagnoses, or medical records
  • Log form submissions to any server or console

3. The Demo Contact Form

The appointment request form on the contact page is for demonstration purposes only. When submitted:

  • All validation occurs client-side in your browser
  • No data is transmitted to any server
  • No data is stored in the browser
  • No appointment is created
  • Form data is immediately discarded after the demo confirmation is shown

4. Third-Party Services

This website loads Google Fonts for typography. Google's privacy policy governs how Google handles requests for font files. No other third-party services are used.

5. External Links

This website may contain links to external websites. We are not responsible for the privacy practices of external sites. External links open in new tabs with appropriate security attributes.

6. Hosting

This website is hosted on GitHub Pages. GitHub's privacy statement applies to the hosting infrastructure. GitHub Pages may collect standard server logs including IP addresses as part of normal web hosting.

7. For Real Healthcare Websites

If this concept were implemented for a real dental practice, the privacy policy would need to address:

  • HIPAA compliance and Notice of Privacy Practices
  • What personal and health information is collected
  • How information is used, stored, and shared
  • Patient rights regarding their data
  • Data breach notification procedures
  • Cookie and tracking disclosure
  • Consent mechanisms for data collection
  • Data retention and deletion policies

8. Contact

This is a fictional demonstration. For questions about this portfolio project, contact Vireon Technologies through their official channels.

9. Changes to This Policy

This policy may be updated to reflect changes to the demonstration website. As this is a non-commercial demonstration, formal change notification procedures are not implemented.

Last updated: 2024. This is a demonstration privacy policy for a fictional website project.
